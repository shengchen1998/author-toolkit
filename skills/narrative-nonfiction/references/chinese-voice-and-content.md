# 中文叙事非虚构 Voice 与 Content 参考

## 使用原则

本参考用于中文稿件的 Voice Editor 和 Content Editor 工作。保留所属模式关于声音一致性、教学清晰度、完整性、事实核查和停止点的流程；以下规则只处理中文表达。判断依据是目标读者、作者人设、章节目的、语体和上下文，示例不是通用替换公式。

不要把英文 `you`／`we`／`one` 的区分逐字译成中文，也不要把英文 passive、词数或句首规则机械移植到中文。中文可以省略清楚的称呼或主语，被动句也可以合理保留。

## 读者称呼：你、我们、大家与敬称

先确定作者与读者的关系，再检查称呼是否一致、包容且不过度承诺共同经验。

- **你**：直接、具体，适合行动建议和个别情境。“你可以先记录三天的支出。”比连续命令更留出选择空间；涉及羞耻、创伤或失败时，“你总是管不住钱”可能把假设强加给读者，可改为“如果支出常常超出预算，先找出发生的情境”。
- **我们**：只有作者确实共享经历、行动或不确定性时才使用。“我们都会逃避困难对话”可能把作者经验泛化；若作者有此经历，可写“我也回避过困难对话，我们先从准备一句话开始”。
- **大家**：适合群体召唤或共同练习，如“大家先比较两种记录方法”。反复使用会稀释指向，正式论证中也不能替代具体主体。
- **敬称**： “您”“各位”可建立礼貌、服务或讲习语体，如“您可以在练习后记录一次观察”。应保持距离感一致，不要在同章无动机地在“你／您／大家”之间轮换；特定身份敬称只在符合读者关系时使用。

称呼清楚时，中文练习可以直接写“写下三个例子”，不必每句补“你”。若目标读者不包含作者，不要用“我们”替读者表态。

## 语体与作者声音

区分口语自然与过度随意、书面精确与名词堆砌。术语密度、幽默、礼貌距离和权威程度应与全书声音档案一致；内容变难时，不必自动变得更学术。

- “对每日任务进行优先级方面的划分”可在普通指导语体中改为“先给今天的任务排个优先级”。
- “焦虑是一种需要被立即消除的东西”可改为“焦虑出现时，先别急着把它赶走”；若原句用于正式定义或强调受事焦点，应按章节功能另行处理。

不要用“更口语”作为唯一目标。回忆录中的克制、专业指南中的严谨和练习中的温暖可以并存，但转换要有章节目的。

## 连接与论证推进

检查“因此、但是、所以、同时、然后、事实上、换句话说”等连接词是否符合真实逻辑，而不只看是否连贯。因果、并列、转折、举例和总结不能互相冒充。

- “他没有坚持记录，因此这个方法对他无效。”因果可能过强；若证据只显示执行不足，可写“记录中断了，目前还无法判断这个方法是否适合他”。
- “睡眠会影响记忆。同时，回忆也需要时间整理。”若第二句是补充而非严格并列，可写“回忆也需要时间整理”并独立成句；若只是两个话题拼接，应调整结构而不是换连接词。
- “首先、其次、最后”适合真实步骤或枚举，不必给每段都加序号。汉语意合句在关系清楚时可以少用一个连接词。

Content Editor 仍需区分文本可支持的推论与需要来源的事实主张，不能用顺滑连接掩盖证据缺口。

## 名词化与功能词

检查“进行、给予、作出”和多层“的”链是否削弱行动主体或拖慢教学，也检查正式语体是否有保留理由。

- “对目标进行分解”可写“分解目标”；“给予自己一次休息的机会”可按语义写“让自己休息一次”。
- “关于习惯的改变的困难的解释”可按所指改为“解释为什么习惯难以改变”。若各层修饰关系并不相同，应拆分而非只删“的”。
- “这次改变让她重新理解休息”简洁自然，不必因为“改变”可作词性转换就硬换成动词句。

避免用“的、对、对于、通过、所”等词的出现次数评分；只有关系不清、语气不符或动作被埋藏时才提出修改。

## 比喻与概念表达

比喻要符合中文搭配、读者经验和全书概念系统，并检查映射能否支持教学。不要为了延续中心比喻而给每个动作都套同一意象，也不要把英文习语直译成陌生表达。

- 以“建筑”为中心比喻时，“先确认需求，再给计划打地基”可以说明准备的重要性；接着写“给计划升帆、瞄准靶心”会混入无关意象，除非作者有意转场。
- “把大目标拆成几级台阶”直观呈现递进；“把大目标切成蛋糕”虽然新奇，却可能只表达分块，未必支持逐级完成的教学点。
- 英文 `touch base` 若实际意为同步进度，可写“我们对一下进度”，不要保留逐字意象。中文成语、方言或文化典故也应确认目标读者能理解。

Content Editor 要检查比喻是否夸大证据、混淆类别或掩盖例外；Voice Editor 要检查它是否仍像这位作者的话。

## 练习措辞与可执行性

练习应写清动作、材料、时限、完成标志和必要的选择空间，称呼与语体跟本章一致。提示语“请、你可以、试着、直接写”要按难度和读者状态选用；安全、创伤或高成本行动不能用统一命令式强推。

- 模糊：“你应当进行一次有效的反思。”
- 可执行：“用十分钟写下最近一次分心的情境：发生了什么、你当时需要什么、下次准备先做哪一个小动作。写不出三项时，先完成一项。”
- 群体练习：“先各自记录，再由自愿的伙伴分享。”比“大家必须轮流公开经历”更尊重边界。
- 有共同经验时可用“我们先列出现状”，但不要替读者承诺结果；面向正式讲习读者可写“请您在表格中记下……”，并保持全章一致。

修改练习措辞后，Content Editor 应重新核对前置知识、步骤完整性、难度和预期成果；Voice Editor 只报告声音与称呼问题，不借润色扩大练习要求。
